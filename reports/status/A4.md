# A4 status: evidence corpus, shared Claude client/cache, validation anchors (2026-10-08)

## Done
- **Shared LLM infra** (`src/rtl/llm/client.py`, `cache.py`), for A5 too. Cached `get_or_call`
  (key = sha256(model, prompt_version, canonical request), with PDFs hashed). Opus 5.5 request defaults:
  adaptive thinking, explicit effort, no sampling params, no forced tool_choice. Also structured outputs,
  citation document blocks, Batch API submit/poll/collect keyed by custom_id (the mapping is kept in the DB so
  it survives restarts), refusal → `RefusalError`, and a price table with batch discount, cache read/write
  and 1 h TTL. Storage: `data/llm_cache/cache.duckdb` (responses, ledger, batches), behind a file lock.
  `pixi run llm-ledger` prints spend.
- **Evidence extraction** (`src/rtl/llm/evidence.py`, prompts `src/rtl/llm/prompts/evidence_v1_*.md` +
  `versions.json` hash lock). Pages are chosen by keywords and sent as sub-PDFs; step (a) asks for cited
  statements, step (b) normalises them into `evidence` rows by claim index. The quote and page always come from
  the API citation, and each quote is checked against the PyMuPDF text of the page. `pixi run evidence --dry-run`
  estimates ~$10.65 (Opus 5.5) / ~$5.33 (`--batch`) for 18 docs: 745 of 2,406 pages sent, 47 requests.
  **Not run: no API key.**
- **Corpus**: `config/evidence_docs.yaml` lists 21 docs. 18 are downloaded (2,406 pages) via `pixi run fetch-evidence-docs`.
  3 are unavailable (RURA board decision 404; National Electrification Plan 2019 and the Power Africa PUE
  catalog for Rwanda return 403).
- **Validation anchors + DHS priors** (`data/processed/validation_anchors/`, README there). RW2025 phone anomaly resolved there.
- **Archetype template** (`src/rtl/archetypes.py`, `data/processed/archetypes/`), with a one-day RAMP smoke test.
- Tests: `tests/test_llm_client.py`, `tests/test_evidence.py` (all with fake API; no real calls).

# A3 climate + DEM: status (2026-10-08)

## Done
- **DEM ready (11:35 BST):** `data/interim/dem_rwa_30m.tif`. Copernicus GLO-30 (6 tiles S02/S03 x E028-E030, recorded in the manifest
  under data/raw/copernicus_dem/2022-05-09/). It is a mosaic on the source pixel grid (no resampling), clipped to the bbox + 0.03 deg.
  EPSG:4326, float32, nodata -32767, 7777 x 6733 px, range 832-4507 m, EGM2008 heights.
- **Raw climate data:** `data/raw/openmeteo/2026-10-08/` holds 33 parquet batches: 528 ERA5-Land nodes (0.1 deg; bbox + 1 ring), hourly,
  UTC 2018-12-31..2024-12-31, with Open-Meteo downscaling turned off (`elevation=nan`), so the values are raw grid values plus the
  model elevation. That used about 8.3k of the 10k weighted calls in the daily free tier. `data/raw/nasa_power/2026-10-08/` holds hourly T2M
  for 4 towns and daily GHI on 16 nodes at 1 deg (2019-2024).
- **`data/interim/climate_h3.parquet`:** 4,034 res-7 cells (parents of all 6,434,247 buildings). `pixi run qa climate_h3` PASS;
  `pixi run test` and `pixi run lint` pass. Diagnostics: `data/interim/climate_h3_diagnostics.json`. Maps:
  `reports/figures/A3_t2m_mean_c.png`, `reports/figures/A3_cdd24_per_year.png`.
- Method: bilinear interpolation to the cell centroid, then + gamma x (cell-mean DEM elevation - interpolated grid elevation), applied to the
  daily series *before* computing degree-days and p95. Days are local CAT days (UTC+2). CDD uses the mean of the 24 hourly values.

## Lapse rate
Regressing node mean T on node elevation over all 528 nodes gives **-6.05 K/km** (R² 0.94), close to the standard -6.5 K/km.
The slope depends on the time of day: about -5.4 K/km at dawn and -6.9 K/km at 16:00. The p95 daily max gives -7.7 K/km.
A single gamma is used for every column. The median absolute correction is 0.36 K (p95 1.4 K).

- **Cooling demand is marginal.** CDD24 > 0 covers 2,019 cells (48% of buildings), but nearly all of it is a few degree-days.

  The building-weighted CDD18 is 712/yr, so the 18 °C base mostly measures "warm, not hot".
- GHI is nearly uniform at 4.73-5.02 kWh/m²/day (1 deg source). Treat it as a regional constant, not a spatial feature.

## Proposed contract notes / decisions for the human
1. Cell elevation is the plain cell mean. Buildings sit on ridges and slopes, so A2r's building `elevation_m` can refine this
   downstream: T_bldg = T_cell + gamma x (z_bldg - elevation_m), with gamma = -6.05 K/km. Consider adding a `lapse_rate_k_per_km`
   column, or documenting gamma in the datasheet.
2. Cooling archetype thresholds: CDD24 is ~0 almost everywhere. Something like tmax_p95 or CDD at 22 °C may separate cooling classes better.
3. Licence: the Open-Meteo free tier is non-commercial only. The data is CC-BY-4.0 plus the Copernicus licence (attribution required).
   Any commercial reuse would need a paid API plan or a CDS re-download (the human needs to decide this). The DEM and NASA POWER are free with attribution.

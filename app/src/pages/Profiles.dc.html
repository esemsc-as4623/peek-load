1 · Usage windows and switch-ons

Each appliance may only run inside its usage windows. RAMP draws random switch-on events there until the day's on-time is used, each lasting at least the appliance's minimum cycle.

2 · Concurrent usage

A home's several bulbs are not all on at once: inside the peak window RAMP switches on about half of them, fewer off-peak. This makes simulated energy below share × number × power × hours.

3 · Many units, many days

Each profile is simulated for 200 units over 28 days (weekdays and weekends) with a fixed seed; hourly means per unit feed every building and area curve in this dashboard.

Opportunity: appliances that scale with the building

Planned

Each profile has a fixed number of appliances per unit (for example, a home's light bulbs and sockets). Scaling the number of light bulbs, power outlets and similar fixtures with the building's footprint area (and floors) would give realistic counts for large homes, shops and institutions, instead of one typical unit for every building.
